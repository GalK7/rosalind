# Rosalind – Bioinformatics Stronghold

My solutions to problems from the [Rosalind](https://rosalind.info/problems/list-view/) Bioinformatics Stronghold, written in Python as practice.

Each problem has its own script (e.g. `gc.py`) and a sample input in `samples/`.

| Problem | Description |
|---|---|
| DNA | Counting nucleotides |
| RNA | Transcribing DNA into RNA |
| REVC | Reverse complement |
| GC | Highest GC content in a FASTA file |
| HAMM | Counting point mutations |
| PROT | Translating RNA into protein |
| SUBS | Finding a motif in DNA |
| PRTM | Calculating protein mass |
| REVP | Locating restriction sites |
| SPLC | RNA splicing |
| ORF | Open reading frames |
| GRPH | Overlap graphs |
